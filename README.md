# Lunar Web

> 月面で、Webを動かすということ。

地球—月の光速遅延、真空での放射冷却、宇宙線によるビット反転——
**Webエンジニアリングが応用物理学になる瞬間** をブラウザで体感する学習用アプリです。

---

## なぜ作ったか

地球で当たり前だった3つの前提が崩れたとき、私たちのコードは何を要求されるのか。
3つの章を通して、それぞれの物理現象が**実際にインフラ設計をどう壊すか**を見て、改善策を考えるためのアプリです。

| 章  | 物理現象     | 数式                                  | 体感できること                                                         |
| --- | ------------ | ------------------------------------- | ---------------------------------------------------------------------- |
| 01  | 光速の壁     | $RTT = 2L/c \approx 2.56\text{s}$     | Raft 3往復が約7.7秒。Strong Consistencyが事実上不可能になる様子        |
| 02  | 真空での排熱 | $Q = \epsilon \sigma A (T^4 - T_0^4)$ | O(n²)アルゴリズムが原子炉コアを赤熱させ、シリコン融点を超える様子      |
| 03  | 宇宙線とSEU  | $R(t) = e^{-\Gamma t}$                | 32ビットメモリが宇宙線で反転し、Hamming(7,4) と TMR が自己修復する様子 |
